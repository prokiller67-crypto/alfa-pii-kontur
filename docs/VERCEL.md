## Лимиты бесплатной конфигурации

- [Vercel Hobby](https://vercel.com/docs/plans/hobby): 1 млн вызовов функций,
  4 CPU-часа и 360 GB-часов памяти за период; квоты общие для проектов аккаунта.
- [Neon Free](https://neon.com/pricing): 0.5 GB хранения, 100 CU-часов на проект,
  5 GB исходящего трафика; засыпание после 5 минут простоя.
- 1000 HTTP-запросов/с × 300 с = около 300 000 вызовов за полный прогон, без ретраев.
  Несколько полных попыток могут исчерпать бесплатные квоты. Доступные попытки на
  портале не означают, что их все покроет Hobby.
- 1000/2000 RPS на этой конфигурации не подтверждены. Локальный результат 1848 RPS
  относится к Docker с Redis и не переносится на Vercel с PostgreSQL.

## Повторное развёртывание

1. Подключить проект Vercel к Neon Free и получить `DATABASE_URL` (pooled) и
   `DATABASE_URL_UNPOOLED` (direct). Не добавлять connection strings в исходники.
2. Задать только в окружении сервера `PII_MASTER_KEY`, `SUPPORT_API_KEY`, `ANALYTICS_API_KEY`;
   ключ шифрования должен совпадать между экземплярами. `PII_LOCAL_DEMO=0`.
3. Для прогона организаторов включить `PII_CHECKER_MODE=1`, `PII_CHECKER_MASK=partial`.
   Этот формат на примере из онбординга даёт `И. И. И.` / `45** ****56`;
   точный вид остальных эталонных масок неизвестен.
   Установить `PII_POLICIES_FILE=config/policies.example.json`, `OPENBLAS_NUM_THREADS=1`, `OMP_NUM_THREADS=1`.
4. `vercel deploy --prod` запускает `scripts/init_postgres.py` по direct-соединению.
   Миграция `migrations/001_pii_state.sql` идемпотентна и не удаляет существующие записи.
5. Проверить `/readyz`, затем POST `/process` в обоих направлениях.

В `/process` checker-режим допускает анонимный запрос по контракту организаторов.
`/v1/mask`, `/v1/restore` и `/metrics` требуют ключ разрешённой системы; локальная
интерактивная демонстрация запускается отдельно по командам из README.

PostgreSQL проверяет TTL по времени сервера. Просроченные строки удаляются порциями
по 2000 при обращениях, с интервалом 15 секунд на экземпляр. История восстановления
Neon может сохранять старый ciphertext; это не сертифицированный банковский контур.

На Vercel endpoint `/metrics` показывает метрики конкретного экземпляра.
Для сводного Prometheus по нескольким экземплярам нужен отдельный сборщик.
