# Демонстрационный экран

Для жюри и разработчика системы-потребителя: ввести текст → увидеть изменённые фрагменты → восстановить.
Главный элемент — два редактора рядом; на телефоне они расположены последовательно.
Визуальный акцент — реальное маскирование в тексте. Нет выдуманных показателей качества и графиков.

Палитра: банковский красный `#E32326`, текст `#17212D`, вторичный текст `#5C6774`,
фон `#F5F6F8`, разделители `#D6DBE1`, подтверждение `#1C7149`.
Helvetica Neue/Arial, левое выравнивание, крупный заголовок приглашает проверить действие.
Вместо витрины одинаковых карточек — единая рабочая поверхность с вводом и результатом.
Данные не отправляются внешним провайдерам; LLM не подключена, что явно указано на странице.
