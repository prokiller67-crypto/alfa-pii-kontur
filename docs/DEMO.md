# Демонстрация до 3 минут

Это сценарий для будущего скринкаста, а не утверждение, что видео уже записано.

**0:00–0:20. Проблема.** Каждая банковская команда отдельно защищает данные перед LLM.
Контур выносит эту обработку в общий модуль с политиками для разных систем.

**0:20–0:55. Живое маскирование.** Открыть локальный интерфейс, выбрать «Обращение клиента»,
нажать «Защитить данные». Показать ФИО, email, телефон, карту и текст с типизированными токенами.
Сказать: «Модель получает обозначения типов данных; исходные значения остаются в нашем контуре».
Уточнить: в этой демонстрации внешняя LLM не подключена, показана граница обработки.

**0:55–1:20. Восстановление.** Переставить токен в правом редакторе, повторить его в предложении,
нажать «Восстановить». Показать точное возвращение значения. Для неизменённой маски показать
полное совпадение с исходным текстом, включая пунктуацию и переносы.

**1:20–1:40. Контекст.** Выбрать публичную информацию: Пушкин, адрес отделения, дата встречи.
Показать отсутствие маскирования на этом примере. Не заявлять, что решены все случаи публичных персон.

**1:40–2:10. Подключение и защита.** Показать `/process`, JSON политики системы,
отключение демаскирования, зависимость ПИН от карты. Объяснить: retry не переключает фазу,
записи зашифрованы, привязаны к системе, имеют TTL, исходные значения не пишутся в логи.

**2:10–2:40. Измерения.** Использовать только актуальные цифры из `VERIFICATION.md`.
Отдельно назвать размер и происхождение набора качества, длительность/шаблон нагрузочного теста,
характеристики машины и отсутствие официальной оценки, пока она не получена.

**2:40–3:00. Завершение.** Показать deployed URL после реального развёртывания и результат
официальной проверки после прогона. До их получения не подменять их localhost и внутренними тестами.

## Каркас презентации

1. Проблема банка и конкретный путь данных.
2. Архитектура + 17 типов + три формата маски.
3. Демонстрация контекста, обратимости, политик и повторных запросов.
4. Качество по категориям и нагрузка: фактические числа с методикой.
5. Безопасность, подключение, ограничения и следующий этап.
